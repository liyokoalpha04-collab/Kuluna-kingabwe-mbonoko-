# KULUNA — La Rue de Kinshasa

Jeu 3D d'action-aventure inspiré de Kinshasa. Jeu final : Android avec Godot.
Ce dépôt contient le **prototype web 3D** (Three.js) pour tester le gameplay.

- `index.html` : le prototype jouable (rue, habitants, véhicules, combat 5 vs 5 à Kingabwa)
- `KULUNA_CONTEXTE.md` : dossier technique et prompt pour les outils d'IA

Jouer : ouvrir `index.html` dans un navigateur (connexion Internet nécessaire).
Règles : outils gratuits, aucun achat sans accord, violence stylisée sans gore.
